# High-Harmonic-Generation-Simulation-Code
High-Harmonic Generation Simulation Code

This code implements a numerical simulation of high-harmonic generation (HHG) based on the Lindblad equation.

Simulations under different physical conditions can be performed by modifying the parameters described in the comments of the core routine, `hhg_mpi.c`.

The output data generated by the main code can be visualized using the provided MATLAB scripts.

Example output data for demonstrating the usage of the MATLAB post-processing codes are included in the `examples` directory.
